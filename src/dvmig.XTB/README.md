# Dataverse Migrator (dvmig)

`dvmig.XTB` is the XrmToolBox plugin for Dataverse Migrator.

It helps you synchronize Dataverse data between source and target environments while preserving audit fields and handling related records.

## Install

- Install from XrmToolBox Tool Library using package id `dvmig.XTB`
- Or install from NuGet.org: `dvmig.XTB`
